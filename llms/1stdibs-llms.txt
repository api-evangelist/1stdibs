# 1stDibs

> 1stDibs is an online marketplace for luxury antiques, vintage and modern furniture, fine art, jewelry, watches, and fashion, connecting a global network of vetted sellers and dealers with buyers of curated, high-end design. 1stDibs does not operate a public REST/OpenAPI developer program; its documented machine-facing surface is an official Model Context Protocol (MCP) server for browsing and searching the marketplace.

## Agent access (MCP)

- [1stDibs MCP Server](https://www.1stdibs.com/soa/mcp/): Official remote MCP server (com.1stdibs/1stDibs), streamable-http transport, API-key auth — browse and search marketplace items.
- [MCP registry entry](https://registry.modelcontextprotocol.io/v0/servers?search=1stdibs): Official Model Context Protocol registry listing.
- [PulseMCP listing](https://www.pulsemcp.com/servers/1stdibs): Third-party directory listing for the official server.
